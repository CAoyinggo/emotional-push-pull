## 一、 评测证据层级与客观边界声明

为杜绝“评测结论超过可审计证据”的过度承诺，本报告严格区分以下四类性质不同的事实：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        评测证据的四层严格区分                           │
│ 1. 场景规范定义 (Definitions) ── 84 个场景用例的输入、must 与 must_not 明确定义│
│ 2. 历史验收记录 (Historical) ── v1.2.0 对 1-30 场景的人工/模型辅助验收记录存档 │
│ 3. 本次工程审计 (Audit) ── 静态结构、有效链接、规则一致性与 Fixture 存在性校验 │
│ 4. 未经验证边界 (Limitations) ── 明确不等于现实关系成功率，不作绝对化承诺   │
└────────────────────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **真实世界有效性与静态审计局限声明**：
> 1. **实验室场景不等于现实成功**：自建评测场景中的规则断言通过，**绝不代表或等同于现实亲密关系的成功、恋爱达成率，更不能保证一定能筛选出合适伴侣或解决深层心理困扰**。
> 2. **静态文件审计不等于模型行为验证**：自动化脚本 [`evals/verify_evals.js`](verify_evals.js) 执行的是静态文件存在性、JSON 语法合法性、Markdown 链接有效性与违禁词清理审计，**并非由外部真实大模型执行的模型端到端推理打分**。在具备独立推理运行环境前，模型端到端推理打分标记为“未执行独立打分”。
> 3. **待独立验收集声明**：场景 49–52 标注为 `independent_validation`（待独立验收场景）。因在工程迭代中参与了规范设计，**不虚构其为未经接触的留出集**，后续应由独立环境执行未见验证。
> 4. **合成测试样本说明**：[`evals/fixtures/`](fixtures/) 目录下的 7 张测试图片均为**人工合成的场景测试样本 (Synthetic Test Fixtures)**，用于校验多模态模型对气泡左右方位、文字模糊标注和重叠截屏去重的处理逻辑，**绝非真实私人聊天实录**，不包含任何真实个人隐私。

## 二、 第六轮专项整改核心架构落地说明

针对两性沟通中普遍存在的“审讯式追问”、“要求对方承认受委屈/让其愧疚”、“借旧事惩罚”以及“因害怕显得弱而故作冷漠”等深层痛点，本轮整改在 [`recovery_and_cold_start.md`](../.agents/skills/emotional-master/references/recovery_and_cold_start.md) 中完整落地了判断与行动体系：

```text
┌────────────────────────────────────────────────────────────────────────┐
│               第六轮整改：停止审讯式追问与恢复自主权架构全景             │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 核心立场去污名化 ── 情绪非低价值、正当沟通不压抑、禁羞辱词、主导权在自主行动│
│ 2. 五类追问幕后研判 ── 正当澄清 / 未修复问题 / 重复行为 / 审讯追问 / 借旧事惩罚│
│ 3. 意图转化四问机制 ── 针对“让对方愧疚”诉求，转化为事实/未决需要/修复行动/自主选择│
│ 4. 具体真实拒绝冷漠 ── 表达四要素；保留脆弱与在乎(边界与关心并存)；拒假装无所谓│
│ 5. 回应质量 7 项评估 ── 事实/负责/改进/接纳情绪；不把不同意见/暂说不清判为撒谎操控│
│ 6. 停止绕圈与战术暂停 ── 缺乏新信息/情绪过载/出现威胁时暂停；明确恢复安排拒冷暴力│
│ 7. 从解释转向行动 ── 偶发改进观察 / 目标不同协商结束 / 反复失约调投 / 伤害退出│
│ 8. 取证与隐私红线 ── 严拒偷看设备/密码/定位/套话陷阱；分析材料边界；常规优先摘要│
│ 9. 自身过失客观看待 ── 实事求是纠偏自身查岗威胁；真诚负责道歉弥补，不绑请客送礼│
│ 10. 八组典型实战示范 ── 14 组前后对比覆盖关键分歧；明确对方不配合非话术失败 │
└────────────────────────────────────────────────────────────────────────┘
```
