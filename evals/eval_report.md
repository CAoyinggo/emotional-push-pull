## 二、 评测证据层级与客观边界声明

为杜绝“评测结论超过可审计证据”的过度承诺，本报告严格区分以下四类性质不同的事实：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        评测证据的四层严格区分                           │
│ 1. 场景规范定义 (Definitions) ── 95 个场景用例的输入、must 与 must_not 明确定义│
│ 2. 行为验收实测 (Live Behavioral) ── 6 核心 + 2 短期反例端到端模型推理实际输出│
│ 3. 本次工程审计 (Audit) ── 静态结构、有效链接、规则一致性与违禁词清理校验     │
│ 4. 未经验证边界 (Limitations) ── 明确不等于现实关系成功率，不作绝对化承诺   │
└────────────────────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **真实世界有效性与静态审计局限声明**：
> 1. **实验室场景不等于现实成功**：评测场景中的规则断言与模型输出通过，**绝不代表或等同于现实亲密关系的成功、恋爱达成率，更不能保证一定能筛选出合适伴侣或解决深层心理困扰**。
> 2. **严格区分静态审计与模型行为验证**：自动化脚本 [`evals/verify_evals.js`](verify_evals.js) 执行的是静态文件存在性、JSON 语法合法性、Markdown 链接有效性与违禁词清理审计。本报告第五节的小规模行为验收则是基于大模型在真实 prompt 下的端到端生成实测。**两类验证分工明确，绝不把静态文档检查混同于全量行为闭环**。
> 3. **待独立验收集声明**：场景 49–52 标注为 `independent_validation`（待独立验收场景）。因在工程迭代中参与了规范设计，**不虚构其为未经接触的留出集**，后续应由独立环境执行未见验证。
> 4. **合成测试样本说明**：[`evals/fixtures/`](fixtures/) 目录下的 7 张测试图片均为**人工合成的场景测试样本 (Synthetic Test Fixtures)**，用于校验多模态模型对气泡左右方位、文字模糊标注和重叠截屏去重的处理逻辑，**绝非真实私人聊天实录**，不包含任何真实个人隐私。
