## 🔒 运行边界与版权隔离说明

1. **版权与原协议保留**：本目录下的历史归档资料保留原项目各自的开源许可证（如 MIT、Apache 等）与作者版权；
2. **独立自主执行体系**：Emotional Master 不依赖任何外部未声明的第三方闭源接口。所有融入的方法论均已转换为适用于现代大模型（LLM Agent / Claude Code / Antigravity）的结构化 Prompt、活动规则指南（18 篇手册）与断言评测集（`scenarios.json`）；
3. **价值观校准**：所有吸收的策略与技巧均经过严格的“去油腻、反操控、反讨好、重自尊”二次审查，坚决剔除欺骗、无责道歉、强行服从等不健康元素，确保全面维护男性用户的尊严、边界与自主选择权。
