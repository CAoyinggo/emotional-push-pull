## 💻 项目简介

很多男性在亲密关系中常陷入两种极端：要么沦为“老好人”，无底线妥协、暗中付出（建立隐性契约），在患得患失中内耗爆发；要么盲目相信低质“PUA套路”，机械打压、虚浮吹嘘，显得既油腻又廉价。

**Emotional Push & Pull（情感推拉）** 是一套建立在临床心理学、高自尊人格与健康沟通哲学之上的智能体系统。它帮助成年男性在保持自尊、判断力与个人边界的前提下，从容表达好感、承接情绪、化解分歧，并在不合适时体面退出。

> **核心原则：**  
> **底层原则用于选择回应方向，不要求在答案中逐条解释。默认只给一条贴合语境的回复；用户要求分析或复盘时，再展开依据。专项模块不得自行增加默认输出栏目。**

## 🏛️ 四层解耦架构 (The 4-Layer Architecture)

为避免知识库膨胀导致日常回复臃肿，系统严格执行“四层职责解耦”：

```text
┌──────────────────────────────────────────────────────────────────┐
│ 1. 思想层 (Philosophy) ── 集中于 mindset_meta_concepts.md        │
│    • Glover：拒绝隐性契约（付出出于心甘情愿，意图与结果解绑）     │
│    • Tawwab：温和非防御性设限（客观事实 + 个人底线 + 行动选择）   │
│    • Gottman：拒绝冷暴力（情绪过载时执行战术安全暂停，准时归来） │
│    • Manson：真实坦荡表达（放弃操控，得之坦然，失之淡然）        │
├──────────────────────────────────────────────────────────────────┤
│ 2. 场景层 (Scenarios) ── 各专项参考手册                          │
│    • 根据具体事实，决定接话、安慰、设限、邀约、暂停或体面止损    │
├──────────────────────────────────────────────────────────────────┤
│ 3. 输出层 (Output) ── 主入口 SKILL.md 严格锁定                   │
│    • 默认只给 1 条 10-25 字即拷即用的话术，不带理论分析与策略说教│
├──────────────────────────────────────────────────────────────────┤
│ 4. 教练层 (Coach) ── 按需展开 (/mock, 截图复盘, /复盘)           │
│    • 仅在用户明确要求分析、对练或复盘时，才展开详细理论与多维评分│
└──────────────────────────────────────────────────────────────────┘
```

## 📸 聊天截图复盘与表达修正

当发送聊天截图或文本并询问“帮我复盘 / 哪些话低价值 / 这句怎么改 / /复盘聊天”时，系统启动专属复盘模式：

1. **情境还原**：区分可见事实、用户补充与未知盲区；识别发言双方，理清先后时间与关系背景，不凭模糊断句脑补。
2. **客观检视**：检查连发追问、过度解释、隐性契约、生疏冒犯、回避责任等具体表达问题；**同时充分肯定真诚主动、认真倾听、就事论事负责道歉与温和设限**。不硬挑毛病，不评价男生本人的价值。
3. **两层隔离**：
   - **当时推荐改法**：10–25 字真实真人表达示范（仅供复盘教学，绝不代表现在补发！）。
   - **现在怎么做**：给出屏幕前最优先的单步动作（默认不追加任何解释/检讨；面对明确拒绝坚决停止联系）。
4. **精炼输出模板**：
   ```markdown
   整体判断：
   [1-2 句话客观定性：指出主要卡点，或说明整体正常顺畅不必过度修正]

   关键复盘：
   - 原话：“...”
     → 问题/适用条件：...
     → 当时推荐改法：“...” (备选：“...”)

   值得保留：
   - 原话：“...” → [做得好的地方，如真诚、倾听、明确；没有时可省略]

   现在怎么做：
   [明确告知当前最优先的 1 个动作，绝不随意补发小作文]
   ```

## 🎛️ 常用操作指令

平时直接丢原话或截图，系统默认秒给回复；需要深入对练或复盘时使用以下指令：

```powershell
# 1. 日常解围（直接发原话或截图）
"她说：'你挺闲啊'，我们平时常开玩笑，怎么回？"
> 忙里偷闲，刚好碰上你。

# 2. 聊天截图复盘与表达修正（发截图/文字 + 复盘请求）
"帮我复盘这段聊天截图，哪些话低价值？当时怎么说更好？现在怎么做？"
/复盘聊天

# 3. 遭遇越界/情感勒索时直接求助
"她说：'你要是不把朋友圈背景换成我，就是不爱我'，怎么回？"
> 我很在乎你，但我习惯按自己的节奏发圈，我们不拿这个证明爱。

# 4. 沉浸式对练沙盒 (/mock)
/mock 慢热回避型
/mock 高压职场型
/mock 直爽调侃型

# 5. 沙盒内伴随指令
/提示    # 暂停角色，给出思路与示范
/教练    # 开启/关闭每轮短评
/复盘    # 针对整场表现生成框架/边界/共情体检报告
/exit    # 随时退出沙盒
```

## 🧪 30 个行为验收场景 (Evals)

项目在 [`evals/scenarios.json`](evals/scenarios.json) 中定义了 30 个独立验收用例，覆盖：
1. **自然接话**（先给简短回复，不长篇大论）
2. **语境不足**（不盲目打好感百分比，区分事实与猜测）
3. **严肃提问**（诚实表达意图，不回避反弹）
4. **明确拒绝**（尊重边界，停止联系，不搞机械冷冻再死缠烂打）
5. **失误负责**（主动道歉改正，不框架压制）
6. **自然节奏**（随缘自然回复，杜绝固定等几分钟套路）
7. **接触同意**（区分赴约与接触意愿，杜绝借交通等借口强行拉手）
8. **模拟对练与退出**（/mock 沉浸互动，/exit 立即退出）
9. **自动边界**（未回消息不连续施压，不编造已发送）
10. **非防御性设限**（面对情感勒索，平静温和守住边界）
11. **冲突安全暂停**（情绪过载时用状态+离开+归期战术暂停，杜绝冷战）
12. **破除隐性契约**（引导平复受害者心态，不发小作文被动攻击）
13. **复盘-正常主动非讨好**（肯定坦荡自然邀约，不把主动判定为低价值舔狗）
14. **复盘-真诚道歉非低价值**（肯定负责道歉，不把道歉当示弱丢框架）
15. **复盘-连发催回复**（指出催促压力，当时改法留白，当下建议停止追问）
16. **复盘-熟人调侃与生疏冒犯双向对照**（刚认识的越界冒犯 vs 熟人打趣默契的语境差异）
17. **复盘-事务求助非好感**（区分事务礼貌感谢与浪漫好感，避免职场尴尬越界）
18. **复盘-信息不全与模糊处理**（文字模糊断句不脑补猜测，不强行心理诊断）
19. **复盘-已发消息无需额外补救**（正常邀约不撤回、不补发自我贬低解释）
20. **复盘-明确拒绝后区分界线**（区分停止恋爱追求与停止一切联系，不影响正当客观事务，不发挽回小作文）
21. **图片实测-左右发言人与角色识别**（结合气泡与头像正确识别女生倾诉与男生承接）
22. **图片实测-多图时序与重叠去重**（去除跨图交界重复消息，理清完整对话时序）
23. **图片实测-模糊文字不脑补**（严重模糊文字标注[无法确认]，拒绝凭空猜测或心理诊断）
