# 💘 情感大师 (Emotional Master) · 祖师爷级实战推拉心法系统

> **“真诚是必杀技，但套路是基本功。讲道理是老师的事，给情绪才是男人的事。”**

本项目是一个专为现代两性社交与恋爱博弈打造的顶配 AI 军师系统。  
系统不仅融合了 **童锦程（祖师爷）式的痞帅松弛感、无解高框架**，更深度汲取并完整收录了 GitHub 顶尖开源情感项目（`qingsheng-skill`、`relationship-training-skill`）的全部核心资产与战法。
