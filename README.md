## 💡 核心机制：15 级抽屉架构与抽屉 0 底座

系统以**“中枢分诊中控 + 抽屉 0 通用底座 + 15 级专项业务抽屉”**模块化运转，接收时间线或聊天记录后秒级定型，首屏直出高情商实战草稿与破局策略：

* **抽屉 0 · 通用底座**：框架自尊（有错负责、无错不认罪）、三不原则（不发长篇小作文/不空头许诺/不自贬）、三分离研读（事实/动因/杂音）、PFC 理性主权、蔡加尼克开环留白、峰终定律（Peak-End 重塑情绪节点，严禁分手反扑期小作文二次充能）、健康性张力植入与知情同意微步试探法则。
* **抽屉 1–5（危机分型）**：情绪作闹型（接情绪给台阶）、防御冷战型（黄金2小时脆弱置换）、权衡利弊型（撤销灰色供给）、失望冷漠型（超预期共情开环留白）、底线崩塌型（彻底物理隔离止损）。
* **抽屉 6–10（相处推进）**：初识破冰接话、升温与关系设计（五种禀赋效应、健康性张力植入与知情同意微步试探）、相容性意愿研判、相亲流水线备忘（三振法则）、测试与翻旧账应对。
* **抽屉 11–15（实战工具）**：截图四问复盘、`/mock` 沙盒对练、`/call` 电话模拟、`/自动` 逐轮副驾、内耗收束替代。

## 🚀 常用指令与入口

* **日常接话**：直接发送聊天记录原话，秒出自然得体可用草稿；
* **危机分诊**：发送时间线或冲突经过，直出分型 SOP、动因透视与红线排查；
* **截图复盘 (`/复盘`)**：发送截图启动四问标准复盘（定性 + 改哪句 + 为什么 + 当下行动）；
* **实战对练 (`/mock [场景]` / `/call [场景]`)**：沉浸式多分支角色扮演或即兴通话对练；
* **副驾与档案 (`/自动` / `/档案 [代号]`)**：逐轮实时草拟或相亲客观事实建档备忘。
