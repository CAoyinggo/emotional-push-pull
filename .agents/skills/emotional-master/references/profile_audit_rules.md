# 展示面与社交主页优化参考指南 (Profile Audit & Self-Expression)

> **“展示面的核心是：真诚、自然地呈现立体的自我，提供舒适的沟通线索，同时严守个人隐私与安全。不搞流水线式人设包装，更不把个人审美偏好伪装成客观打分标准。”**

---

## 一、 核心定位与评估原则

`/展示面` 或相关自然语言请求触发此指南。

1. **尊重用户的展示目的**：
   - 每个人使用社交软件或朋友圈的目的不同（有的希望寻找严肃长期伴侣，有的希望结交志同道合的兴趣同好，有的仅作为生活随笔记录）；
   - **首先了解或尊重用户的核心诉求**，不强行要求每个人都按照所谓“高价值网红人设”去包装。
2. **拒绝机械打分与刻板配比**：
   - 严禁输出虚假的分数（如“头像 7/10、总分 68 分”）；
   - 不强加僵化的内容百分比（如“必须生活 40% + 爱好 30%”）；
   - 不强行凑“三大问题”，有针对性提出 1–2 条切实可行的改进建议即可。
3. **真实自洽胜过过度修图与演戏**：
   - 鼓励使用近期、真实、神态自然的照片，避免过度滤镜导致线下见面产生严重失真落差；
   - 仅使用用户真实的日常生活素材，绝不教导用户去借豪车摆拍、伪造高消费场景或虚构虚假生活方式。
4. **隐私与人身安全底线**：
   - 提醒用户注意隐去敏感个人信息（如工作证件、常住小区门牌、机票登机牌条形码、车牌号等）；
   - 避免发布可能危及人身、财产安全的实时行程隐私。

## 二、 核心维度的自然审视

在审视主页展示时，建议从以下四个维度进行温和、实用的观察：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        主页展示的核心观察维度                           │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 真实度与近况 ── 是否为近期本人、神态是否自然、是否避免过度失真修图 │
│ 2. 视觉舒适度 ── 光线明亮清晰、神情舒展放松、避免单一重复大头照       │
│ 3. 话题线索度 ── 个人简介与动态能否提供真诚、有具体细节的交流切入点   │
│ 4. 隐私安全度 ── 是否保护好个人核心住址、财务与敏感工作隐私           │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 照片与视觉表达
- **清晰自然**：第一张或主头像能看清本人的面貌与眼神，神态随和放松、自然微笑；
- **关于自拍与场景**：自拍并非绝对不能用，但若“所有照片均为同角度浴室镜子自拍”，容易显得信息单一且光线欠佳。建议适度补充一些户外、日常活动、咖啡馆或专注爱好的半身/全身生活照，展现多元的生活状态；
- **展示真实爱好**：无论是徒步、烹饪、摄影、读书、打球，还是安静的拼图、手办整理，真实热爱的状态最能吸引同频的人，胜过刻意模仿的网红打卡。

### 2. 文字简介 (Bio / 签名)
- **拒绝空洞标签堆砌**：单纯写“爱旅游、爱美食、爱生活”往往缺乏记忆点；
- **提供具体细节作为交谈引子**：
  - *平淡*：“喜欢做饭和看电影。”
  - *具体有温度*：“做饭味道尚可，摆盘略胜一筹；周末常在老电影院出没。”
- **保留留白与轻松感**：不必写成长篇自我简历，保留 1–2 个容易引起好奇或互动的小细节即可。

## 三、 常见平台的语境考量

不同平台的社交契约与氛围各异，建议顺应平台语境：

1. **日常社交工具（如微信）**：
   - 兼顾生活分享与职场/熟人关系，保持得体、自然与真实；
   - 减少连续多条密集倾倒负面情绪长文或纯营销刷屏，多记录真实生活片段与个人心得。
2. **交友软件（如 Tinder、Bumble、探探）**：
   - 视觉节奏较快，主图建议清晰明亮、能看清长相与生活状态；
   - 个人介绍突出“一个生活细节 + 一个可互动的共同话题”，方便对方自然开启第一句话。
3. **基于深度或兴趣的社区（如 Soul、青藤之恋）**：
   - 用户更注重三观、思维方式与生活观念的共鸣；
   - 文字与动态可适当分享深入的个人阅读、职业思考或生活感悟，但切忌说教或好为人师。

## 四、 建议输出模板（温和实用 · 不强加偏好）

```markdown
### 主页与动态观察建议

- **当前优势**：[指出做得好、真实自然的地方，如眼神舒展、爱好具体、有亲和力]
- **优化建议**：[指出最关键的 1-2 个具体调整点，如光线更明亮、补充一张全身生活照、简介增加一个具体细节]
- **参考示例**：
  - 简介调整参考：“[提供一条符合用户真实风格的口语化文字]”
  - 选图建议：“[如：可以用上周末徒步那张换掉较暗的室内自拍]”
```
