# 关系观察备忘笔记与六维评估指南 (Relationship Observation Notes)

> **“爱一个人，首先要看见‘真实的他者’，而非自己幻想出来的完美投影。记录不是为了算计，而是为了克服恋爱脑带来的认知失真，客观评估双方的核心匹配度、行为风险与真实意愿。”**

---

## 一、 认知去盲区：区分“客观事实”与“主观投射”

许多人在陷入迷恋时，容易开启“光环效应”，把对方的冷淡美化为“高冷内向”，把对方的反复无常美化为“神秘莫测”，或者把普通客气当成深度好感。

```text
┌────────────────────────────────────────────────────────┐
│ 认知过滤器 (Reality vs Projection Filter)              │
├────────────────────────────────────────────────────────┤
│ 1. 真实可查的行为事实 (Facts)：言语原句、履约记录、实际投入 │
│ 2. 你的主观情绪投射 (Projections)：“她肯定是害羞/她很在乎我” │
│ 3. 悬而未决的未知盲区 (Unknowns)：家庭背景、三观深层底色   │
└────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **关系判断的基本单位**：
> 判断的核心是**“双方在当前条件下适合怎样相处”**，坚决不给某个人贴永久标签（严禁输出“她就是短期型女生”、“她只配短期”、“有心理困扰就不配谈恋爱”等偏见）。好感不等于可靠，不适合长期不等于适合短期，没有伤害行为不等于完全没有相处风险。

## 二、 核心评估维度与相处模式审视

评估关系与相处时，必须将以下六个独立维度分开考量，切忌“一好百好”或“一票全盘否定”：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        核心观察与六大评估维度                          │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 发展意愿 ── 观察主动性、延续话题、见面履约、改期诚意与实际投入      │
│ 2. 表达期待 ── 严肃恋爱、婚姻、随缘相处，或明确的非排他短期            │
│ 3. 长期相容性 ── 相互尊重、可靠履约、双向投入、冲突修复能力、目标匹配   │
│ 4. 短期适配性 ── 成年自愿知情、意图对称透明、排他/健康共识、无木马心态  │
│ 5. 行为风险 ── 具体的羞辱、威胁、控制、欺骗、持续越界与财务施压         │
│ 6. 用户自身状态与选择 ── 真实目标自省、避免讨好/过度防备、对自身行为负责 │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 发展意愿 (Willingness to Progress)
- **正面线索**：主动开启或延续话题、积极分享日常生活、愿意见面并准时履约、拒绝某次邀约后主动提出明确替代时间、关心并记住你的事情、持续有实际行动投入。
- **负面/平淡线索**：长期被动不主动发起、仅用“嗯/哦/哈哈”应付、连续多次拒绝邀约且从不给替代时间、从未有实质行动投入。
- **分寸把控**：这些只是当下参考线索，不是终身证明；严禁凭秒回或单次言论定论；**严格区分“明确不愿意发展”与“目前没有足够积极证据”**；严禁输出虚假的好感百分比。

### 2. 对方已表达的关系期待 (Stated Relationship Intent)
- **观察核心**：对方明确表达的是严肃长期、结婚、随缘相处，还是明确的非排他短期。不凭个人臆测代替对方表达。

### 3. 长期相容性 (Long-Term Compatibility)
- **观察核心**：
  - **相互尊重与边界**：彼此能否平等表达意见，能否体面接受对方的拒绝；
  - **双向投入与互惠**：相处是否相互体贴、共同分担，而非一方单向供养；
  - **沟通与冲突修复能力**：发生分歧时是倾向于就事论事解决，还是冷暴力摔门、极端发泄？
  - **言行一致与可靠度**：答应的事能否落地，变动能否提前真诚沟通；
  - **核心现实目标**：对定居城市、生活节奏、消费观等重要事项是否存在重大不可调和的冲突。
- **女方是否珍惜与投入专项核查 (Reciprocity & Cherishing Checklist)**：
  - ① **主动了解**：是否主动了解男方生活、工作与喜好，而非全由男方单向提问；
  - ② **尊重界限**：是否尊重男方的时间、精力、工作节奏以及合理拒绝；
  - ③ **回馈分担**：是否在接受好意时表达真诚感谢，主动回馈或分担开销/安排；
  - ④ **守约可信**：是否遵守约定，有变动能否提前真诚沟通；
  - ⑤ **共同修复**：发生冲突时是否愿意共同面对并解决，而非单向问罪施压；

### 4. 双方短期相处适配性 (Consensual Short-Term Suitability)
- 双方成年、充分知情且自愿同意，无虚假承诺，随时可终止。
- 区分三种情况：双方知情尝试但无长期承诺；用户无法接受不转正长期；表面答应短期暗中图谋转正（严禁木马式短期，但不将前两种扣帽子）。

### 5. 行为风险 (Behavioral Risks & Violations)
- 识别具体的羞辱打压、暴力威胁、控制社交、习惯性欺骗、持续践踏底线或财务索要。严重威胁直接自保，无需反复观察。

### 6. 用户自身的目标、状态与选择 (User Autonomy & Choices)
- **真实目标与底线核查**：检查用户是否真实想要该关系，还是仅仅因为沉没成本不愿放弃、因外貌不断降低底线、因孤独妥协接受自己不需要的关系、发生亲密后擅自假定对方已承诺、或长期压抑自己的需要；
- **自省核心**：
  - 我是否在无错时习惯性道歉？
  - 我是否在对方忽冷忽热时反而加倍付出时间金钱？
  - 我是否因过度防备而把对方正常的善意关心冷酷推开？
  - 我自身是否存在迟到失约、施压催促、言语越界或不尊重对方边界的过失？
- **分寸把控**：客观看待自身责任，有错就改，无错不求饶，绝不盲目迎合。不搞性格心理诊断，不强加表单。
  - ⑥ **非功利相处**：是否平时正常互动，而非“只有在需要帮忙、倒苦水、求消费时才热情”。
  > **应对原则**：若缺乏珍惜与投入，直接指导用户表达需要、拉开距离或停止推进，**坚决不教用户靠做局、试探、假装有其他追求者等小动作挽回关注**。
- **分寸把控**：有吸引力不等于适合长期相处；暂时对你没兴趣也绝不等于对方人品差。可以探讨生活目标、吸引力与习惯，但不替用户预设婚育或经济偏好。

### 3. 短期相处适配性 (Short-Term Compatibility)
- **观察核心**：
  - 双方是否均为完全民事行为能力成年人，且能自由表达同意；
  - 彼此对当下的关系期待是否完全透明一致（均不进入排他长期承诺）；
  - 双方能否成熟沟通排他性、个人隐私与性健康保护措施；
  - **自省防坑**：用户自身是否口头答应短期，内心却幻想通过顺从和身体亲密让对方“回心转意”转为长期（特洛伊木马式短期，极具内耗风险）。

### 4. 行为风险 (Behavioral Risk)
- **重点识别**：具体的言语人身羞辱、暴力威胁、强行限制社交与监控隐私、习惯性撒谎欺骗、被设立底线后反复恶意踩踏、刚接触便索取大额财物。
- **分寸把控**：严格遵守心理识别边界，**绝不做远程心理障碍诊断**；不因对方伤心委屈就判定在操控；无法确认动机时评价行为对自己的实际伤害；严重威胁与暴力直接止损自保，无需反复验证。

### 5. 用户自身的状态与行为 (User's Behavior & Responsibility)
- **自省核对**：
  - 我是否在习惯性自动认错？
  - 我是否因害怕对方不高兴而不敢表达合理拒绝？
  - 我是否在对方忽冷忽热时反而加倍付出时间金钱？
  - 我是否因过度防备而把对方正常的善意关心冷酷推开？
  - **我自身是否存在迟到失约、施压催促、言语越界或不尊重对方边界的过失？**
- **分寸把控**：客观看待自身责任，有错就改，无错不求饶，绝不盲目迎合。

## 三、 四类可选结论在备忘中的应用

根据事实证据，备忘记录可归入四类判断之一（或其组合）：
1. **值得继续探索长期关系**（具备积极线索，继续了解，非打包票适合结婚）；
2. **双方期待一致时，可以考虑短期相处**（成人自愿、知情透明，说明成立条件，不因长期不合就乱推）；
3. **目前证据不足，继续了解或先澄清**（接触尚浅，保持松弛，不强行定性）；
4. **不建议继续恋爱或亲密推进**（明确拒绝、目标重大冲突、实质伤害风险或自身无法接受，不人身攻击对方）。

## 四、 观察档案轻量范式（严守隐私原则）

用户输入 `/档案 [代号]` 或要求记录对象信息时，系统仅按需协助梳理关键要点，绝不保存敏感个人真实姓名、身份证、具体住址或私人聊天原图。

### 1. 观察档案标准模板
```markdown
### 观察档案：[代号/昵称]
- **基本互动节奏**：[慢热型 / 快速型 / 观望型]
- **当前关系结论**：[值得探索长期 / 期待一致可考虑短期 / 证据不足 / 不建议推进]
- **发展意愿观察**：[如：线上聊天回复较慢，但线下履约准时且主动送小礼物，意愿积极]
- **相容性/适配性观察**：[如：能认真倾听我的工作烦恼，三观较为契合；但异地规划待沟通]
- **对方珍惜与投入核查**：[如：主动分担下午茶、尊重我的加班拒绝、日常有来有回 / 缺乏回馈，仅在索取时热情]
- **行为风险排查**：[暂无 / 如：刚认识曾借情绪要求我买昂贵礼物，已设限]
- **自身状态反省**：[如：前面有些焦虑催回复，目前已调整为留白专注自我]
- **下一步推进建议**：[保持当前同频互动，下周发起低压力线下轻活动]
```

### 2. 存储路径与环境隔离规范
- **禁止提交代码仓库**：档案绝对禁止写入当前项目 Git 跟踪目录，杜绝随代码推送到公共或远程仓库。
- **推荐存储路径**：默认保存在用户本地专属数据目录（如 `~/.gemini/antigravity/user_data/profiles/[代号].md`）或用户指定的本地私有笔记路径。
- **隐私底线**：Skill 承诺**不主动另存私人资料、不隐式跨会话追踪**。仅在用户明确指示时才在本地执行档案读写。

### 3. 档案保存流程与读回核对 (Save & Post-Write Check)
1. **情境 A：用户已明确发出保存指令（如“把xx存入档案”或“/档案 [代号] 保存”）**：
   - **直接执行写入**，避免已经明确下达指令时仍繁琐询问“你确定要存吗？”；
   - **写入后读回核对 (Post-Write Check)**：保存后简要输出落盘路径与已存要点卡片供用户核对：
     > *“已为您将【小林】的观察摘要保存至本地 `profiles/小林.md`。核对要点如下：[要点卡片]。如需修改请随时告知。”*
2. **情境 B：用户未明确要求建档（日常咨询或复盘中提及对象特质）**：
   - 默认仅基于当前聊天进行沟通辅导，不主动提示或催促用户建档；
   - 绝不隐式在后台自动提取画像，不虚构跨会话记忆能力；仅当用户主动要求“帮我记下来/建档”时才提供建档支持。

### 4. 同名对象消歧与防串档机制 (Duplicate Name Disambiguation)
当用户查询、调阅或更新 `/档案 [代号]` 时，若本地检索到多个同名或名称相近的对象（例如有两个“小林”）：
- **绝对禁止**：严禁系统自作主张随机选择一个，也严禁将两人的历史互动记录、偏好与边界混杂合并！
- **标准消歧交互**：系统必须先暂停操作，列出各自已知的关键背景特征（时间、场景、主要特征）供用户选择确认：
  > *“检测到本地有 2 份关于‘小林’的档案：*
  > *1. 小林（大学同学，爱好摄影，建档于 9 月）*
  > *2. 小林（新入职同事，运营协同，建档于 10 月）*
  > *请问您当前指的是哪一位？或请指定新代号（如‘小林-摄影’）以便区分。”*
- 用户明确指定后，仅针对对应单一档案进行调阅或更新。
