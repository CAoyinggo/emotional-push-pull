# 轻度推拉：反差、自嘲与松弛表达

这里的推拉是双方享受的语言反差，不以制造焦虑、贬低、自尊受损或依赖为目的。

## 使用条件

双方已经有轻松玩笑语境。陌生、办事、严肃提问、对方难过或表达边界时，先直接回应，不硬套推拉。

## 三种可用方法

### 自嘲

对方：“你做饭怎么样？”
可选：“拿手菜是点外卖，最近准备进修。”

只有符合真实情况时使用；认真问生活习惯则认真答。

### 场景反差

对方：“我今天效率超高。”
可选：“厉害，我还在跟待办清单谈判。”

调侃落在自己，不踩对方外貌、能力或经历。

### 接住调侃

对方：“你还挺自恋。”
可选：“偶尔，今天额度刚好没用完。”

只适用于明显玩笑。对方认真指出不适时不以此回避，先问清或承认问题。

## 不用的方法

- 不把“讨厌”“不合适”“别联系”自动解释成喜欢。
- 不设计冷落、嫉妒或假装忙碌来控制回复。
- 不说“你没那么好看，不过我勉强接受”之类贬低后施舍认可的话。
- 不用玩笑逃避失约、冒犯等具体责任。
- 不机械规定推拉比例、字数对等或等待分钟数。

判断标准：对方能否轻松接，也能否自在不接。接不住就换自然表达，不再加码。
