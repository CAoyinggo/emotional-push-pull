# 沉浸式亲密沟通演练沙盒 (Crush Sandbox Simulator)

> **“对练的目的不是寻找‘通关秘籍’或背诵标准话术，而是提供一个安全的模拟环境，练习真实表达、感知边界、从容应对分歧与拒绝，并做出适合自己的下一步选择。”**

---

## 一、 系统架构与交互协议

模拟沙盒帮助用户在不同社交语境中进行多轮对话演练。**系统支持自然语言交互，斜杠命令仅作为便捷快捷方式，非使用前提**。

```mermaid
flowchart TD
    Start["发起对练<br>(自然语言或 /mock [场景])"] --> Init["初始化具体场景与情境背景<br>(地点、互动阶段、待讨论事项)"]
    Init --> TurnLoop["进入单轮沉浸角色对练"]
    TurnLoop --> UserInput["用户输入回复或表达"]
    UserInput --> Router{是否触发控制指令 / 请求?}
    Router -- "求助 / 提示" --> Hint["军师提供思路参考与可选表达<br>不推进剧情，等用户重新输入"]
    Router -- "开启/关闭建议" --> Coach["切换旁白反馈开关<br>(角色回复后追加 1 句简要观察)"]
    Router -- "复盘 / 总结" --> Review["客观复盘评估<br>(真实意图/边界保留/责任担当/信息获取)"]
    Router -- "退出 / 结束" --> Exit["退出沙盒模式，回到常规对话"]
    Router -- "常规对练输入" --> SimNPC["模拟对象依据情境作出真实反馈<br>(可接受/可婉拒/可提异议/可结束)"]
    SimNPC --> TurnLoop
```

## 二、 场景化情境演练（非固定人格模型）

对练使用**具体的现实场景与可变的偏好**，**绝不将模拟角色当作真人确定性心理模型，更不根据职业贴上固定的心理学或依恋标签**。

### 常见对练场景设计

1. **场景一 · 刚认识初期的轻量邀约与协调**：
   - **情境**：刚加上联系方式不久，双方聊过一两轮日常，用户尝试发起周末轻量活动邀约。
   - **多样化后续分支**：
     - 分支 A（欣然接受）：时间合适，爽快答应；
     - 分支 B（日程冲突但有诚意）：说明当天有事，主动提议改期；
     - 分支 C（含糊婉拒 / 日程冲突）：表达近期较忙、这周末不便外出或暂时无法赴约，但未提出改期提议（**审慎判定：这仅能证实对当前具体邀约或时间安排的婉拒，整体发展意愿尚属未知，绝不能直接断言为“明确无意发展”**）；
     - 分支 D（明确表达无恋爱意愿）：礼貌且明确说明只想做普通朋友、目前不考虑约会发展（**确凿边界：属于明确设立的拒绝界限，应体面尊重并停止追求**）。
   - **演练重点**：练习清晰发起邀约、从容接纳对方的拒绝或改期，不恼羞成怒也不反复纠缠；面对含糊婉拒能得体退回日常节奏、不强行逼问，面对明确拒绝能保留自尊体面停止。

2. **场景二 · 双方出现分歧或合理批评**：
   - **情境**：因用户迟到半小时、或某句话让对方感到冒犯，对方发来严肃意见或质问。
   - **多样化后续分支**：
     - 分支 A（看到真诚道歉后愿意翻篇）：接受合理的补偿与改进承诺；
     - 分支 B（依然情绪不佳，需要时间）：说明现在有点生气，想先各自冷静；
     - 分支 C（借题发挥过度升级）：言语超出事件本身，进行人身贬低。
   - **演练重点**：练习就事论事承担实际责任，区分合理批评与人身侮辱，温和守住个人尊严。

3. **场景三 · 面对激将、比较或证明要求**：
   - **情境**：对方提出超预算消费、要求交出手机密码、或用“别人都愿意”施加比较压力。
   - **多样化后续分支**：
     - 分支 A（接受男方的合理边界）：尊重男方的原则，回到正常沟通；
     - 分支 B（继续坚持己见）：进一步施压，测试男方是否退让；
     - 分支 C（价值观明显不合）：双方无法协商一致。
   - **演练重点**：练习不接证明任务、平静陈述个人真实意愿与原则，以及在无法调和时体面退出。

4. **场景四 · 对方反应平淡或生活忙碌**：
   - **情境**：对方回复较慢、字数简短，没有提供太多话题延伸。
   - **演练重点**：练习不焦虑连环追问、不自我贬低自证、自然收束对话并回归自己的现实生活。

5. **场景五 · 讨论未兑现的约定与重复失约**：
   - **情境**：双方此前已达成提前告知的约定，但对方再次无通知失约，并反问“你怎么又提以前的事”。
   - **演练重点**：练习把泛化指责改为具体问题，客观引用约定说明重复模式，不扣“翻旧账”帽子，根据反馈决定是否调整投入。

6. **场景六 · 表达受伤感受而不施压审讯**：
   - **情境**：生病或重要时刻遭遇对方敷衍，内心感到难过与委屈。
   - **演练重点**：练习坦诚表达自身真实受伤与失望，不进行恶意动机定罪，不逼迫对方发誓证明内心，也不退缩伪装成冰冷的“随你/无所谓”。

7. **场景七 · 识别对话绕圈与合理战术暂停**：
   - **情境**：双方在同一分歧上反复车轱辘话争执，情绪逐渐过载。
   - **演练重点**：练习主动叫停无意义争吵，输出标准的暂停三要素（说明状态 + 暂时离开 + 约定恢复沟通时间），不搞冷暴力断联惩罚。

8. **场景八 · 对方不认错/不配合时的体面自主退出**：
   - **情境**：发现双方核心价值观严重不相容，对方持续嘲讽或拒不沟通。
   - **演练重点**：练习不把“逼对方认错道歉”当做离开的前提，保留完整自尊，利落体面结束推进。

## 四、 /复盘 客观成长复盘维度

当用户请求复盘时，系统调取过去的对练记录，**绝不给出虚假的 0-10 打分、不评判“推拉节奏”，也不宣称存在“唯一最优解”**。复盘聚焦以下六项具体行为维度：

```text
┌────────────────────────────────────────────────────────┐
│               模拟对练客观复盘要点                       │
├────────────────────────────────────────────────────────┤
│ 1. 真实意图表达 ── 是否清晰表达了自己的真实想法、时间与意愿？ │
│ 2. 彼此选择尊重 ── 是否尊重对方表达不同意见与拒绝的权利？     │
│ 3. 具体责任担当 ── 确有过失时是否就事论事负责，有无推诿甩锅？ │
│ 4. 边界与自尊保留 ── 面对施压与激将时，是否守住了自己的底线？ │
│ 5. 有效信息获取 ── 是否通过交流看清了对方的真实诉求与相容性？ │
│ 6. 下一步自主选择 ── 用户选择继续推进、协商、还是体面退出？   │
└────────────────────────────────────────────────────────┘
```

### 核心复盘理念与无羞辱原则
1. **严禁创建羞辱角色**：系统在生成场景与模拟对象时，**绝对禁止创建所谓“怨夫型”、“作女型”、“低价值型”等标签化羞辱角色**；
2. **不以对方认错、服从或变热情为通关标准**：现实中对方享有不认同、不道歉或坚持己见的自由；在面对对方不配合或拒不认错时，**用户能够保持冷静、看清事实、守住底线并自主决定调整投入或体面退出，同样属于极为成功的演练**；
3. **真实表达不等于低价值**：允许在演练中真诚表达失望与难过，不把合理表达当成软弱；
4. **同一情境允许多种得体风格**：温和沉稳、平实质朴、幽默随和均可，鼓励保留用户原本真实的语言风格，不强加油腻的人设包装；
5. **基于可观察证据，严禁读心与动机脑补**：教练旁白（`💡 [观察点]`）与复盘建议必须严格基于对话中**可观察到的事实证据**，**绝不能使用假想的“读心术”或沙盒幕后预设来代替可观察证据**。当模拟对象回复“这周不太方便/近期比较忙”时，教练只能提示“对方婉拒了当前具体时间安排，整体发展意愿尚属未知”，严禁断言“对方已明确无意发展”；指导用户落落大方接纳当前拒绝，不纠缠追问，退回正常生活节奏。

## 五、 真实聊天导入与动态化身构建（Crush 模拟器 · 源自恋爱沙盒体系）

为了克服通用模拟对象“过于机械或理想化”的缺陷，沙盒支持导入已去敏的真实历史聊天记录，快速提取对方的沟通风格特征，构建高保真的动态拟真化身（源自 `TammyTan516/relationship-training-skill` 实战沉淀）：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   动态化身与发送前预演流                               │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 导入去敏记录 ── 提取语速节奏、标点/emoji习惯、话题转移与口吻特征    │
│ 2. 拟真化身构建 ── 生成高还原度的交互对象，保留对方的真实反应倾向     │
│ 3. 发送前实战预演 ── 犹豫未决的话（邀约/设限/表白）在沙盒中率先试发   │
│ 4. 多分支反馈演练 ── 预先体验对方答应、推脱、质疑等可能走向，打消恐慌 │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 动态化身特征提取要素（严守隐私边界）
- **绝不收集真实敏感信息**：用户粘贴历史文本前，必须隐藏或替换双方真实姓名、单位学校、电话住址等隐私；
- **沙盒提取的五维属性面板 (Persona Attribute Spec)**：
  1. **回复篇幅与断句**：习惯单句回复、短句连发，还是长篇大论？
  2. **口头禅与助词**：是否高频使用“哈哈”、“emm”、“确实”、“哭笑表情”或偏冷淡克制？
  3. **情绪敏感度与防御阈值**：面对调侃是自然大笑、还是容易戒备防卫？
  4. **话题主动性与抛接球习惯**：是喜欢就事论事只答不问，还是习惯主动反问拓展？
  5. **生活节奏投影**：是工作繁忙型（回复间隔长但有诚意）还是随性闲聊型？
- **生成化身开场**：沙盒初始化后以提取出的拟真口吻主动发出一句日常开场，带用户进入高保真语境。

### 2. 发送前实战预演 (Pre-flight Sandbox Practice)
- 当用户正准备向心仪对象发送一条重要消息（如：首次模糊邀约、提出周末具体安排、回应对方的敏感质疑、或设立自己的消费/时间底线），内心忐忑不安、担心“说错话暴雷”时：
- **沙盒预发机制**：在真实发出前，先将草稿发给沙盒化身；
- **化身分流反馈**：沙盒自动呈现 3 种不同情绪状态下的真实反馈分支：
  - *分支 A（积极顺畅）*：对方当下心情良好、顺利接话或爽快应邀；
  - *分支 B（日常平淡/忙碌）*：对方语气简略、或因工作忙碌提出时间调整；
  - *分支 C（产生歧义/设防）*：对方对草稿中的某处措辞感到困惑或产生误解；
- **军师教练即时微调**：副驾教练同步标出用户草稿中的闪光点与潜在歧义点，协助做最小必要润色；
- **效果**：帮助用户在真实发出前建立全盘心理预期与应对预案，彻底打消“开盲盒”恐慌。

## 六、 `/call [场景]` 电话与即兴约会临场模拟模式（源自全栈约会教练体系）

许多技术从业者与内向男性在文字聊天中能够深思熟虑，但一旦切换到“实时语音通话”或“线下第一次见面”，容易瞬间陷入心跳加速、舌头打结、冷场尴尬的瘫痪状态。本模式专门针对实时口语临场反应进行强化（源自 `connecttoriyan/dating-coach` 理念）：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   /call 电话与即兴对练核心机制                         │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 拟真口语语流 ── 包含自然语气词、停顿（“呃……”）、环境背景与生活小插曲 │
│ 2. 五大临场挑战 ── 破冰开场、死亡提问、3秒冷场自救、突发插曲、优雅收尾  │
│ 3. 通话复盘卡 ──── 四维评估：语速呼吸、倾听/表达比、承接自然度、松弛度  │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 模拟交互特色与五大实战挑战模式
- **触发方式**：输入 `/call [场景]`（如 `/call 晚上下班后第一次打微信电话`，或 `/call 约会餐厅刚坐下破冰`）；
- **拟真语流交互**：
  - 模拟对象发出带口语化特征的消息（包含口语停顿、轻微语病、真实生活背景声描绘，如“喂？听得到吗……我刚出地铁，风有点大”）；
- **内置五大典型临场挑战模式**：
  - **挑战 1 · 开头 30 秒破冰**：训练打破尴尬的第一句话，通过当下的客观环境或轻松调侃自然开场；
  - **挑战 2 · 接住猝不及防的提问**：对方突然抛出“你平时周末都在干嘛？”或“你平时跟女生打电话也这么紧张吗？”，练习不慌乱自证，以坦荡自嘲与真实细节从容化解；
  - **挑战 3 · 突发冷场 3–5 秒自救**：双方突然没话说了，练习不使用油腻低俗段子硬凑，而是用“承认现场安静 + 抛出开放式观察”自然重启话题（“刚才说到那家店，我突然想起来……”）；
  - **挑战 4 · 真实环境突发插曲**：模拟突然信号不好、服务员上菜打断、或者路上喇叭声，练习从容应对现实意外；
  - **挑战 5 · 得体收尾与优雅挂断**：不恋战、不在气氛耗尽前硬撑，在聊得最开心的高潮处主动得体收尾（“跟你聊挺开心的，时间不早了你早点休息，我们改天再聊”）。
