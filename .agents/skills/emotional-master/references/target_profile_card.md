# 用户与对象档案

档案用于延续上下文，不是回答前置条件。普通“怎么回”直接帮助；只有用户要求保存、建档或明确启用档案功能时才写入。用户不保存时，仅使用本次会话上下文。

## 存储位置

- Windows：`$env:APPDATA\emotional-push-pull\`
- macOS / Linux：`~/.emotional-push-pull/`
- 无文件工具或没有持久化能力：提供可复制摘要，不声称已保存。

目录：`user-profile.md` 保存本人资料，`targets/{代号}.md` 保存对象摘要。不得写到项目、版本库或 Codex 系统记忆中；用户指定其他位置时遵循其选择，并提醒是否位于仓库内。

兼容旧版：用户曾启用档案时，可检查 Windows `$env:APPDATA\.qingsheng\` 或其他系统 `~/.qingsheng/` 中的相关文件。说明来源，不自动迁移、覆盖或删除，不复制全部档案。

## 建档与更新

先确认对象代号；同名或指代不清时问一个区分问题。默认用代号，避免真名、手机号或精确地址。文件名中的路径分隔符、冒号、通配符等替换成短横线，拒绝空名称、点目录和 Windows 保留设备名；解析后必须位于 targets 目录内。

只记用户提供或任务范围内实际核实的信息，未知留空。区分事实、推测、用户期望和建议；建议未被执行不能写成既成事实。换对象时分别加载，不能串档。

更新时保留用户手写内容，只改相关字段。写入后读回核对，告诉用户实际完整路径；失败则说明未保存。用户要求删除时，只处理对应文件并确认结果。

## 最小模板

```markdown
# 对象：{代号}
更新日期：
来源与时间范围：

## 已知事实
- 怎么认识 / 平台：
- 关系背景：
- 对方明确表达的意愿或边界：

## 当前判断
- 有依据的判断：
- 未知 / 待确认：

## 近期进展
- 日期 / 事件：
- 上次建议：
- 是否执行 / 实际反馈：

## 下次可接的话题
- 基于真实共同经历的线索：
```

本人资料仅保存用户愿意提供的兴趣、表达习惯和真实经历，不要求完整问卷。

## 素材采集

用户已有截图或文字就直接使用，不重复索要。用户明确要求查看某软件中的某对象时，如环境提供相应工具，可搜索联系人、会话、资料或相关动态入口；先核对对象、发言人和时间范围。重名只问必要的区分信息，不读取无关会话。

不从头像或昵称猜年龄、职业、性格。够用就停止，仅存必要摘要，不另存原始截图或私聊全文。看不到的内容不猜；需登录或界面不可访问时说明具体卡点，再请用户提供最少文字或截图。只读资料不表示获准发送消息或修改资料。
