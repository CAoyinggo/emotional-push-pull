# 冷场、分歧与恢复联系

先区分普通暂停、沟通分歧和明确结束，不统一处理成冷冻后重启。

| 情况 | 建议 |
| --- | --- |
| 表示忙、回复慢或话题自然结束 | 留空间，不追问“怎么不理我”；以后有真实话题再联系 |
| 自己说错话或失约 | 承认具体问题并补救，不靠玩笑逃避责任 |
| 双方有分歧但愿意谈 | 说感受和需求，听对方看法，不贴人格标签 |
| 拒绝邀约 | 接受，不改成“顺路”“帮忙”继续约；以后是否再提看新的双向互动 |
| 只当朋友或不想谈恋爱 | 接受边界，可以选择普通相处或退出 |
| 要求别联系、拉黑或明确结束 | 停止主动联系，不换账号、不请朋友说情、不安排重启 |
| 分手后需交接物品等事务 | 只通过必要、可用的约定渠道处理，不借机劝复合 |

## 简短表达

- 忙碌：“好，你先忙。”
- 自己失约：“今天没按约定到，是我的问题。抱歉。”
- 拒绝见面：“好，没关系。”
- 停止联系：若尚需回应，可说“明白，尊重你的决定。”；已结束或拉黑就不再补发。

## 恢复普通联系

没有停止联系的要求，之前双方愿意互动时，可围绕真实共同话题轻量联系一次。素材必须真实，不虚构旧物、升职、偶遇或朋友故事。再次无回应就不追加。

不承诺冷却几天能恢复好感，不用动态或新恋情刺激对方。改善生活服务于用户自身，不保证复合。
